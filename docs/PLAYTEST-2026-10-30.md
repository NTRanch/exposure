Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped Lua core under wasmoon in
  demo mode plays each day from a fresh start. Pass = the day closes
  WON on the first attempt (a loss fails the gate; nothing restarts).
- `busted tests/exposure_spec.lua` (estate PUC Lua 5.4.8): 14 specs,
  validation + adversarial split, against the identical core file the
  page ships.
- `node tools/settings-check.mjs`: settings + archive bridge
  round-trips with clamps; settings reachable from boot, ungated.
- `node tools/perf.mjs`: step+draw budget for the VM seam.
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: the day board legible
  at a glance (slots, attention, ledger), her four tracks with bars
  and pending lines, three readable offer cards, no text collisions.
  First pass found three FAILs (title/attention collision, track-name
  collision, caption clipping); all fixed, re-captured, re-inspected
  PASS. A raster-advance audit over all screens followed (breakage
  B-4): CLEAN.
